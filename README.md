# Instituto Pró-Vida — Landing Page Premium

Landing page institucional de alto padrão desenvolvida para o **Instituto Pró-Vida**, localizado em Rio Pardo de Minas (MG).

Projeto com arquitetura **Modern Minimal Luxury Healthcare**, focado em credibilidade, usabilidade editorial, navegação fluida, acessibilidade e conversão direta via WhatsApp.

---

## ✦ Tecnologias Utilizadas

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**
- **Google Fonts** (Newsreader & Plus Jakarta Sans)

---

## ✦ Estrutura e Funcionalidades

1. **Header Sticky & Mobile Menu**: Navegação rápida com logotipo oficial preservado e botão de agendamento em destaque.
2. **Hero Principal**: Título editorial, fotografia real da fachada da clínica com enquadramento arquitetônico e CTAs direcionados.
3. **Catálogo de Atendimentos com Busca Reativa**: Pesquisa por texto em tempo real, filtros por categoria (*Consultas médicas, Exames, Odontologia, Outros atendimentos*) e botão expansor de catálogo.
4. **Links Inteligentes para WhatsApp**: Mensagens pré-configuradas e codificadas por atendimento e por profissional para o número oficial `(38) 99928-3598`.
5. **Faixa de Benefícios**: Pilares da clínica com iconografia minimalista.
6. **Corpo Clínico**: Apresentação dos profissionais com foto, especialidade, CRM/CREFITO e botão de consulta individual.
7. **Sobre o Instituto**: Apresentação institucional e estrutura física na Cidade Alta.
8. **Avaliações**: Área de transparência e ética para exibição de depoimentos verificados.
9. **FAQ Interativo**: Perguntas frequentes com accordions acessíveis.
10. **Contato e Localização**: Bloco de fechamento em contraste com mapa interativo e rota no Google Maps.
11. **Mobile Floating CTA**: Barra inferior fixa nos dispositivos móveis para facilidade de agendamento.

## ✦ Como Executar Localmente

### Pré-requisitos
- Node.js (versão 18+)
- npm ou pnpm

### Instalação
```bash
npm install
```

### Modo de Desenvolvimento
```bash
npm run dev
```

### Build de Produção
```bash
npm run build
npm run preview
```

## ✦ Versão Standalone (Sem dependências)

O projeto inclui o arquivo `Instituto_ProVida_Redesign_Premium.html`, uma versão autônoma e autocontida que pode ser executada com duplo-clique em qualquer navegador offline.
